RaceDay Part 2 Code

RaceDay API: Part 2 code, ready to copy

What to do

  1. Install Visual Studio 2022 with the ASP.NET and web development workload.
  2. Create a new project: ASP.NET Core Web API, name it RaceDay.Api, solution name RaceDay, framework .NET 8. Tick "Use controllers".
  3. Delete the template's WeatherForecast.cs and Controllers/WeatherForecastController.cs.
  4. Add a second project to the solution: xUnit Test Project, named RaceDay.Tests, .NET 8. Delete its default UnitTest1.cs. Right-click Dependencies, Add Project Reference, tick RaceDay.Api.
  5. For each file below: double-click the file name in Solution Explorer to open it (or right-click the project, Add, New Folder / New Class), select everything, tap Copy here, and paste over it. Folder names must match the path shown.
  6. The two .csproj files hold the NuGet packages. Open each by double-clicking the project name, replace the contents with the text below, and save. Visual Studio then restores the packages.
  7. Build, open Test Explorer, run all tests. Then run the API and use Swagger.
